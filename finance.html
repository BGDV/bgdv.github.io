Finance: personal assistant

iOS · Personal finance tracker, fully local

Runs locally — no network, no analytics. See the Privacy Policy.

How it works

  1. Finance: personal assistant is a program designed to maintain and record personal finances.
  2. The program runs locally and doesn't work with the network. No data is collected or sent. Everything is stored only on your device.
  3. The application supports multi-user mode.
  4. After creating a user, you are prompted to create the required accounting profile. If desired, the profile can be hidden from the list.
  5. The main screen consists of the tabs Income, Expenses, Statistics and Settings.
  6. In each of the Income and Expenses sections, you create categories into which amounts are entered.
  7. Categories can be swapped, deleted or renamed. When deleting a category that contains amounts, the program offers to transfer those amounts to another category or discard them.
  8. The interface has a "monthly" division with convenient fast scrolling forward or backward.
  9. The Statistics section displays the total amount of funds received, funds spent, and the difference. Open "By categories" to view statistics per category.
  10. The graph visually shows the dynamics of income and expenses in the selected period as red and blue lines.
  11. You can search for notes attached to amounts.
  12. Settings let you toggle the display of payment date and notes next to each amount.
  13. You can enable a password to enter the application.
  14. You can also change the profile, log out, delete the profile or erase all data.
